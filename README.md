# File Organizer CLI

Un script de automatización desarrollado en **Python** para organizar carpetas desordenadas clasificando archivos automáticamente según su extensión.

## Características
- Clasificación automática en categorías (Documentos, Imágenes, Código, Ejecutables, Archivos comprimidos, Otros).
- Creación dinámica de directorios según sea necesario.
- Manejo de rutas mediante consola de forma interactiva.

## Tecnologías Utilizadas
- **Python 3** (Librerías nativas: `os`, `shutil`, `datetime`).
